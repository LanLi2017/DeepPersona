Proposal · Problem → thesis

表面不同不等于行为不同；成功相同也不等于经验相同

现有计数的问题

轨迹数、文本熵、action 去重和 reward 都可能把同一策略的重复执行当作新经验。

proposal 的核心判断

训练数据应该由它带来的新增、可学习的行为来定价，而不是由表面多样性或数量来定价。

构造一个 reference-free 的完整轨迹 kernel：通过语义等价的环境 transition比较行为冗余，并验证它能否预测 pass@k 与边际学习价值。
对象：完整 interactive trajectory，而非单步文本相似度Measure before optimize

G1 · What counts as different?

E0 / E1 / E2：把风格差异与策略差异分开

E0 · 表面等价

措辞、ID、序列化不同；信息、调用效果和执行骨架相同。

例：一致的实体重命名、工具格式变化。

E1 · 执行等价

低层调用、无害顺序或冗余检查不同；实质子目标和恢复逻辑相同。

例：多一次查询、交换独立 read 顺序。

E2 · 策略不同

信息覆盖、依赖顺序、关键状态效果或恢复策略发生实质变化。

这是项目真正需要测出的“新经验”。

标签描述相对 anchor 的行为关系成功 ≠ 同策略

Progress · Stage conclusion

我们验证了判别管线，但还没有验证“策略多样性”

可以得出的结论

  • E0 机械对照可被稳定识别
  • 多模型能发现 reward-positive 的低质量轨迹
  • 长轨迹可以通过结构化 diff 降低审阅负担

不能得出的结论

  • 当前 metric 能识别成功策略差异
  • 行为多样性能够解释 pass@k
  • 多样轨迹能够提升 post-training

Next · Dataset readiness gate

什么证据允许我们进入 metric 实验？

数据门槛

  • 每个任务有 ≥2 条高质量成功策略
  • E0、E1、E2 三类都有足量样本
  • E2 不依赖 reward、长度或格式捷径
  • 跨任务切分，避免同题泄漏

标注门槛

  • 三模型多数共识只是候选筛选
  • 所有 E2 与模型分歧均需人工复核
  • 至少抽查机械 E0，防止变换改变语义
  • 冻结 rubric 后才比较各类 metric
通过后：H2 metric validation失败则修订任务或策略生成方式
